📌 Mini-Project Architecture & Operations

Every modification in this admin console directly executes parameterized SQL operations on the database via the C++ backend:

  • Movies: Supports INSERT, UPDATE, and referential-safe DELETE.
  • Theatres & Screens: Creating a screen automatically generates a 25-seat auditorium grid in SEATS.
  • Shows: Checks for collision conflicts on the screen before performing INSERT INTO SHOWS.
  • Bookings: View live customer orders; canceling a booking invokes an atomic SQL transaction that updates BOOKINGS and releases all junction records in BOOKING_SEATS.
