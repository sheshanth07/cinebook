# CineBook — Movie Ticket Booking System

A complete, beginner-friendly full-stack cinema ticket booking system developed for the college **Database Systems Design** curriculum.

---

## 🌟 Project Highlights

- **C++ Backend:** High-performance, lightweight HTTP server using modern C++17 (`cpp-httplib`, `nlohmann/json`).
- **Real Database Persistence:** Every single form performs real parameterized SQL operations permanently saved to disk.
- **Dual Database Drivers:**
  - **Oracle Database (OCCI):** Full production Oracle SQL scripts (`database/schema.sql`, `database/sample_data.sql`, `database/useful_queries.sql`) with genuine Oracle data types (`NUMBER GENERATED BY DEFAULT AS IDENTITY`, `VARCHAR2`, `TIMESTAMP`) and OCCI C++ connectivity code.
  - **Local Persistent Relational Engine:** Embedded SQL engine (`cinebook.db`) compiled directly into the binary with enforced foreign keys, check constraints, and atomic transactions. Runs out-of-the-box on any Windows machine without requiring a 10 GB Oracle installation.
- **Concurrency & Double-Booking Protection:** Atomic database transactions and unique constraints guarantee that the same seat can never be double-booked for the same show.
- **Separate User & Admin Logins:** Secure SHA-256 database authentication. Tickets cannot be booked without customer login, and the Admin Dashboard is guarded against unauthorized access.
- **Attractive Cinema Dark UI:** Modern responsive frontend (HTML5, CSS3, vanilla JavaScript) with live seat maps, simulated payments, and admin dashboard.

## 🚀 Quickstart Guide (Windows)

### Option 1: Run Pre-Compiled Server (Zero Setup)
The application is already compiled and ready to launch!
1. Double click `run.bat` or open PowerShell in the project directory:
   ```powershell
   .\run.bat
   ```
2. Open your web browser and visit:
   ```
   http://localhost:8080
   ```
3. The server starts with rich sample data auto-seeded into `cinebook.db`.
4. You will arrive at the **CineBook Portal** login screen:

| Portal | Email | Password | Role |
|---|---|---|---|
| **Customer / User** | `rahul@example.com` (or create new account) | `user123` | Books tickets, selects seats, views orders |
| **Customer / User** | `priya@example.com` | `user123` | Books tickets, selects seats, views orders |
| **Admin Console** | `admin@cinebook.com` | `admin123` | Manages movies, auditoriums, schedules, stats |

*Note: 1-Click quick login buttons are provided directly on the login screen for instant viva demonstration.*

### Option 2: Recompile from Source with Visual Studio MSVC
To compile fresh on Windows using Microsoft Visual C++ Build Tools:
```powershell
.\build.bat
```
This compiles the C++ backend and produces `cinebook_server.exe`.

## 🗄️ Oracle Database Deployment (College Lab / Oracle XE)

If you have **Oracle Database 19c, 21c, 23ai, or Oracle Database Express Edition (XE)** installed:

### 1. Run the Oracle SQL Scripts
Open **Oracle SQL Developer** or **SQL*Plus**:
```sql
-- Connect to your Oracle pluggable database (e.g. XEPDB1)
CONNECT system/your_password@localhost:1521/XEPDB1;

-- Run Schema DDL
@database/schema.sql;

-- Run Sample Data
@database/sample_data.sql;

-- Run Useful Queries and Views
@database/useful_queries.sql;
```

### 2. Configure CineBook for Oracle
Edit `config/cinebook.conf`:
```properties
DB_ENGINE=oracle
ORACLE_USER=cinebook
ORACLE_PASSWORD=cinebook_secret
ORACLE_CONNECT_STRING=localhost:1521/XEPDB1
```

### 3. Compile with Oracle OCCI (Optional)
If Oracle Instant Client SDK is installed:
```powershell
mkdir build && cd build
cmake -DUSE_ORACLE=ON ..
cmake --build . --config Release
```

## 🎓 Viva Voce Key Talking Points

- **8 Relational Tables:** `USERS`, `MOVIES`, `THEATRES`, `SCREENS`, `SEATS`, `SHOWS`, `BOOKINGS`, `BOOKING_SEATS`.
- **Normalization:** Fully normalized to **3NF** to prevent update anomalies.
- **Transactions:** Uses SQL Transactions (`BEGIN TRANSACTION` / `COMMIT` / `ROLLBACK`) for booking and cancellation.
- **Security:** SHA-256 password hashing and parameterized SQL queries to eliminate SQL injection vulnerabilities.
